02 / 怎么玩

从打开到变强，五步走完

整个游戏循环：进去 → 打 → 变强 → 再来一局。每一步都有明确的正反馈。

1

登录进入

支持手机号验证码或邮箱登录，首次登录自动注册，不用填一堆资料，几秒就进游戏。登录后数据云端同步，换设备也能接着玩。

2

开始战斗

电脑用 WASD 移动 + 鼠标瞄准射击，空格冲刺闪避；手机用左侧虚拟摇杆 + 右侧射击键，还有滑动手势闪避。没打过也能玩，第一波敌人很温和。

3

击杀敌人、收集星星

打死敌人掉落 ⭐ 星星，波次清空也有奖励。星星是局内货币，用来在暂停菜单买装备、升级武器。连杀还有额外奖励。

4

每 5 波打 BOSS

敌人会越来越强：血更厚、跑更快、伤害更高。第 5、10、15、20 波是 BOSS 战——BOSS 血厚、会远程弹幕攻击，还带护卫小兵。这是每局的压力测试点。

5

阵亡 → 复活 → 变强再来

死了不是结束。可以看广告免费复活、用复活令牌、花钻石，或者邀请好友帮你复活。每局结束记录战绩，金币和钻石跨局累积，用来永久提升属性——下一局永远比这一局更强。

开局手枪起步，敌人从四周涌来
混战屏幕震动 + 粒子特效，越打越密集
03 / 核心功能

六个撑起整个游戏的系统

每个功能都解决一个具体问题，而不是"为了有而有"。

① 武器系统 —— 四种枪，各有一套升级树

解锁后永久拥有、跨局保留。每把枪有 3 条独立升级路线（伤害 / 射速 / 特殊属性），最高各 10 级。

② 三货币经济 —— 每种钱花在不同的地方

货币范围怎么来用来做什么
⭐ 星星局内击杀敌人、清波奖励、连杀买装备、升武器（武器跨局保留）
🪙 金币跨局累积签到、每日挑战、钻石兑换永久提升角色属性、买自动射击
💎 钻石跨局累积充值、签到奖励、成就买皮肤、复活、兑换金币/星星
设计意图：三种货币各管一段——星星管"这一局怎么打"，金币管"长期怎么变强"，钻石管"外观和便利"。 这样玩家每一局都有收获，又不会因为一局打崩就白玩。

④ 好友复活 —— 死了发个链接，朋友把你捞回来

游戏最有意思的机制。阵亡后生成一条专属分享链接，发给好友；好友点开进游戏，你就能满血复活并获得 3 秒无敌护盾。双方都有奖励（各 +50 🪙 +5 💎）。

  • 跨设备互通：好友在电脑、你在手机，照样救得回来——不限制同端。
  • 三层防自刷：设备 ID + 账号哈希 + 本地历史记录，防止自己刷自己。
  • 四种复活方式：看广告（免费）/ 复活令牌 / 好友助力 / 花钻石，每种每局限用一次。
分享复活两步流程：① 分享链接 → ② 核验复活。链接可一键复制或直接分享到微信/QQ。

⑥ 手机的完整适配 —— 不是"能打开"，是"玩得爽"

  • 虚拟摇杆：左手拇指推方向，右手点射击，符合手游操作习惯。
  • 滑动手势闪避：不用找按钮，直接朝想闪的方向一滑。
  • 竖屏自动提示旋转：横屏体验最佳，竖屏会提示旋转设备。
  • 刘海屏安全区适配：全面屏手机上按钮不会被挡住。
  • 自动降载保证流畅：移动端自动降低特效开销，优先保帧率。

技术选择与理由

技术点实现方式为什么这么做
渲染Canvas 2D + requestAnimationFrame 自研游戏循环零依赖，任何浏览器直接跑，包体最小
框架纯 Vanilla JS，无 React / Vue / jQuery游戏状态高频变更，虚拟 DOM 反而是负担
后端Supabase REST API 直连（未装 SDK）好友复活要跨设备同步，又不想引依赖
数据埋点客户端事件采集 → 批量上报 → 实时看板用真实数据驱动决策，而不是凭感觉调参
皮肤美术全部程序化 Canvas 绘制（渐变/发光/粒子）项目没有美术资源，用代码画反而能做得更系统
移动端虚拟摇杆 + 触控手势 + 性能自动降级手游用户占三分之一，必须真能玩
离线可用Service Worker 缓存网络差时也能加载

做了数据埋点，用真实数据说话

所有关键行为（开局、死亡、复活、广告、购买、签到、成就）都在客户端埋点，落到 Supabase 后在看板实时聚合。

  • 累计 1,996 条埋点事件，覆盖 24 个活跃日
  • 累计 133 局对局，56 次复活
  • 商店购买中 71% 是皮肤——玩家愿意为外观付费
  • 移动端事件占 35%，验证双端适配确有用户
数据驱动的一个例子：数据显示 92% 的开局都用手枪（免费初始武器）， 说明多数玩家还没打到能解锁新武器的波次就阵亡了。这直接指向"前期难度偏高 / 武器解锁门槛偏贵"的调优方向。

过程中踩过的坑（真实复盘）

  • 好友复活怎么跨设备？换设备后身份标识不一样，最初救不回来。解法：登录时额外生成一个由账号派生的跨设备标识，复活令牌同时投递给设备 ID 和账号标识，两条路任一命中即算成功。
  • 数据库权限把功能卡死了。Supabase 建表向导默认只给"已登录"角色写权限，但游戏客户端用的是匿名密钥，导致写入被拒。解法：显式给匿名角色授予最小必要权限。
  • 暗色皮肤在暗背景上看不见。"暗影刺客"名字要求它暗，但战场本身就是近黑色。解法：不靠填充色表达存在感，改用发光描边与光点。
  • 敌人围攻时玩家被淹没。实测截图里角色位置只剩一团红。解法：给玩家加一层深色底衬，保证剪影永远可辨。
线上数据看板实时读取 Supabase 事件表并聚合。左侧复活转化漏斗、死亡波次分布、登录方式；右侧复活方式占比、武器使用分布、商店购买排行。可访问 survival-arena.com/dashboard.html
